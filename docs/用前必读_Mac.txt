========================================
  Claude 稳定网络环境 · 一键配置工具
  （macOS 版）  用 前 必 读
  请先花两分钟读完
========================================


【先确认你的 Mac 芯片】

本版本只适用于 Apple 芯片（M1 / M2 / M3 / M4……）的 Mac。
Intel Mac 未测试，而且本包里的程序和 Clash 安装包都是 arm64，Intel Mac 不适用。

怎么查看：点屏幕左上角苹果图标 →「关于本机」→ 看「芯片」一行。
写着 Apple M1 / M2 / M3 / M4 等就可以；写着 Intel 就不要运行这个版本。


【这个工具是干什么的】

帮你把 Claude 的网络环境配好，让你的流量从一个干净的美国家庭住宅 IP
出去，而不是从人人都在用的公共机场 IP 出去——后者是封号的主要原因。

原本这套流程要手动点几十步、还容易点错。这个工具帮你自动完成。


【怎么用】

1. 把压缩包解压出来（不要在压缩包里直接双击运行！）
2. 双击「启动Claude网络配置.command」
3. 会打开「终端」窗口，跟着提示回答几个问题就行

包里的几个文件要放在同一个文件夹里，别分家。
中途随时可以关掉窗口，进度会自动保存，下次双击接着走。


========================================
  ⚠️ 重要：Mac 会拦一下，这是正常的，有解
========================================

因为这个程序没有购买苹果开发者签名，macOS 可能会拦。别按提示文字猜，
直接按你实际看到的现象处理：

【弹出「身份不明的开发者」或「已损坏」】

  macOS 15 实测可用的办法：
  1. 打开「系统设置」→「隐私与安全性」；
  2. 如果页面要求，先点左下角的锁并输入本机密码解锁；
  3. 往下找到刚刚被阻止的程序，点「仍要打开」。

  较老版本的 macOS 也可能支持右键程序再选「打开」，但 macOS 15 上这条
  不一定出现，所以优先照上面的「隐私与安全性」操作。

【双击毫无反应 / 终端闪一下就没了 / 看到 Killed】

  打开「终端」（启动台 → 其他），输入下面这行，注意 xattr -cr 后有一个空格，
  然后把解压出来的整个文件夹拖进终端窗口，按回车：

      xattr -cr 

  拖进去会自动补上文件夹路径。处理完成后，再双击启动器。
  这一步清除的是下载文件夹的隔离标记，不会修改 Clash 配置。

【启动器仍然打不开】

  可以直接双击同一文件夹里的「claude-net」，功能完全一样。

★ 电脑上装过别的代理软件的，先看这一条

  【现象】

    配置到「导入订阅」那一步时，弹出来的不是 Clash Verge，
    而是你电脑上另一个代理软件（比如 Mihomo Party、FlClash），
    订阅被导进了它里面。然后本工具报「Clash Verge 没有接收到订阅」。

  【原因】

    导入订阅用的是 clash:// 这个「协议」，它是公共的 ——
    任何 Clash 类软件都能把自己注册成它的处理程序，
    而整个系统里只能有一个主人，谁后注册谁说了算。

    所以你装的另一个软件把它抢走了，订阅就送到它那儿去了。

  【怎么办】

    第一步：把 Clash Verge 完全退出（菜单栏图标 → 退出，
            不是点左上角红叉），然后重新打开它。
            Clash Verge 启动时会把这个协议抢回来。
            然后重新双击启动器即可。

    第二步：上面那步做完还不行，重启一次电脑，再跑一遍。
            （已经有两位用户是这样解决的。）

    第三步：还不行的话，把那个代理软件[卸载]掉，再跑一遍。
            这是最彻底的办法，实测有效 ——
            软件删掉了，它注册的 clash:// 也就跟着没了。

  ★★★ 注意：把那个软件关掉是没有用的 ★★★

    这一点很反直觉，但实测确认过 —— 系统是按「注册信息」去找处理程序的，
    那个软件就算完全没开，也会被系统自动拉起来，照样把订阅接走。

    所以别在「关掉它」上面浪费时间。要么让 Clash Verge 把协议抢回来，
    要么把那个软件卸载掉。

  ⚠️ 配置完成后，有一件事千万别做

  别去点 Clash 里【代理】页面右上角的「链式代理」按钮！

程序会把配置重新写回去，然后让你在 Clash 里点一下刷新 ——
那下刷新必须你自己点，程序不会替你重启 Clash（那样反而会把它弄坏）。


========================================
  连不上 Claude 怎么办
========================================

【最常见的第一名：还开着别的梯子】

  两个代理软件会抢「系统代理」，谁后启动谁赢。
  结果是浏览器的流量从那个软件出去了，根本没走我们配的美国 IP。

  ★ 工具现在会主动查这一项，查到会直接告诉你是哪个程序抢的。
    它查两件事：系统代理指没指向 Clash、以及那个端口到底是不是 Clash 在听
    ——后者很重要，有过一次现场是别的软件先占了 Clash 要用的端口，
    两边端口号完全一样，看起来天衣无缝，流量却全从那个软件出去。

  办法：把别的梯子完全退出（菜单栏图标 → 退出，不是关窗口），
  然后把 Clash 的「系统代理」开关关掉再打开一次。

  ★★★ 退出了还是不行？那就把那个软件卸载掉 ★★★

    这是实测出来的：有些代理软件光「退出」不够 ——
    它可能在后台留了守护进程反复把系统代理抢回去，
    也可能开着虚拟网卡（TUN）在网络层截流量，那跟系统代理开关无关。

    现象是：你明明把 Clash 的系统代理打开了，浏览器出去的还是老梯子的 IP。
    而那个 IP 正是我们要避开的「脏 IP」，等于这套配置白配了。

    ★ 现场经验：把那个软件直接卸载，再重新跑一遍本程序，就正常了。

    舍不得删的话，至少确认它没有开机自启、也没有开 TUN / 增强模式。

  ★ 千万别自己把系统代理手动改到本工具的专用端口上。
    那个端口是给 Claude Code 命令行用的，直连美国 ISP、绕开分流规则。
    改过去之后，微信、国内网站、系统更新也全从美国 IP 出去 ——
    绕地球一圈再回来，慢、容易触发验证码、还可能被判成异地登录，
    同时白白消耗机场的流量配额。

【Mac 专属：系统代理开关点了不生效】

  现象：Clash Verge 里「系统代理」的开关点开了、界面上也显示是开的，
  但浏览器打开 ip.net.coffee 一看，还是国内 IP。

  ★ 这不是本工具的故障，是 Clash Verge 在 macOS 上的一个已知问题。
    改系统代理需要管理员权限，而它没有弹出授权框，于是静默失败 ——
    开关看着是开的，系统那边其实一个字都没写进去。

  你可以自己确认。打开「终端」，输入：

      scutil --proxy

  如果 HTTPEnable、HTTPSEnable、SOCKSEnable 全是 0，就是这个问题。

  【办法一（推荐）：改用 TUN 模式】

    Clash Verge → 设置 → 打开「TUN 模式」。
    第一次会让你安装「服务模式」并输入开机密码，装一次就好。

    TUN 在网络层接管流量，不依赖系统代理，绕开了上面那个问题。
    而且它比系统代理管得更宽 —— 命令行工具、桌面应用也能一并覆盖。

    ★ 开好之后一定要验一下，别想当然：
      打开 https://ip.net.coffee ，往下拉到「网站分流测试」那张表，
      看 claude.ai 和 anthropic.com 那两行 —— 应该显示你买的美国住宅 IP；
      国内网站那几行 —— 应该显示你自己的 IP。
      两个都对上了才算配好。

    ★ 如果开了 TUN 之后连国内网站也变慢或打不开，那是 TUN 自己的毛病。
      关掉它，改用下面那个办法。

  【办法二（TUN 也不行再用）：改系统安全设置】

    系统设置 → 隐私与安全性 → 拉到最底下的「高级…」
    → 关掉「需要管理员密码才能访问系统级设置」
      （不同系统版本名称略有差异）

    ★ 这条能修好问题，但请先想清楚代价：关掉它之后，
      以后任何程序都能不问密码修改这台电脑的系统设置，不只是 Clash。
      这是在降低整机的安全级别。

      TUN 只需要给 Clash 一次性授权，范围小得多。
      所以除非 TUN 也用不了，否则不建议动这里。


【第二名：前置节点连不通】

  1. 打开 Clash Verge → 点左边「代理」
  2. 找到「Claude前置节点（跑不通就来这里换）」这个组
  3. 手动挑一个节点换上（先试日本 / 新加坡 / 香港）
  4. 重新双击启动，选「体检一下」再测

  注意：别在「Claude前置-自动测速」那个组里点，那里点了不生效。


========================================
  出问题了怎么办
========================================

配置完成后，工具会在这个位置生成一份《使用须知》：

    ~/.claude-net/使用须知.md

里面有：日常怎么用、养号建议、指纹浏览器怎么配、常见故障速查表。

想检查网络还正不正常：再双击一次启动器就会自动体检。

【出错了要发什么给我】

每次运行都会自动记日志，出问题就把这个文件发我：

    ~/.claude-net/运行日志.txt

  在「访达」里按 Shift + Command + G，粘贴上面这个路径回车就能找到。
  里面记录了程序做了什么、卡在哪一步。
  密码和订阅 token 已经自动打码成 ***，可以放心发。

★ 注意：同目录下的 state.json 里有你的账号密码明文，
  那个不要发给任何人。


【想从头再来怎么办】

打开「终端」，把 claude-net 这个文件从文件夹里拖进终端窗口，
然后在后面空一格打上 reset，回车：

    /你的路径/claude-net reset

然后重新双击启动器就是全新开始了。
