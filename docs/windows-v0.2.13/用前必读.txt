========================================
  Claude 稳定网络环境 · 一键配置工具
  用 前 必 读（请先花两分钟读完）
========================================


【这个工具是干什么的】

帮你把 Claude 的网络环境配好，让你的 Claude 流量从一个干净的美国家庭住宅 IP
出去，而不是从人人都在用的公共机场 IP 出去——后者是封号的主要原因。

原本这套流程要手动点几十步、还容易点错。这个工具帮你自动完成。


【怎么用】

1. 把压缩包解压出来（不要在压缩包里直接双击运行！）
2. 双击 claude-net.exe
3. 跟着提示回答几个问题就行

就这么简单。中途随时可以关掉窗口，进度会自动保存，下次双击接着走。


========================================
  ⚠️ 重要：会遇到两个吓人的提示，都是正常的
========================================

【第一个：蓝色的「Windows 已保护你的电脑」】

双击之后，Windows 大概率会弹出一个蓝色窗口，写着：

    Windows 已保护你的电脑
    Microsoft Defender SmartScreen 阻止了无法识别的应用启动

这不是病毒，是因为这个程序没有购买「代码签名证书」（一年好几百到上千块，
个人开发者一般不买）。任何没买证书的小工具都会弹这个。

怎么办：
    点【更多信息】  →  再点【仍要运行】

就可以了。


【第二个：杀毒软件可能报毒】

某些杀毒软件（尤其国内那几个卫士）可能会报毒。这是误报，原因是：

  · 这个程序是用 Python 打包成 exe 的，这种打包方式是误报重灾区
  · 它会修改网络代理配置、会安装软件、会启动浏览器
    ——这些行为在杀毒软件眼里，跟木马的特征有点像

怎么办：
    在杀毒软件里点【添加信任】或【允许】即可。

如果你实在不放心，不要运行它，直接删掉就行。


========================================
  运行前的准备
========================================

【必须你自己准备的（工具帮不了）】

1. 一个 Google 邮箱
   ★ 强烈建议用你自己用了很多年的老号。
   ★ 新注册的 Google 号会让 Claude 觉得你可疑，风险高很多。

2. 一个能付美元的方式（买 ISP 用）

   在这一家买：
       ProxySeller   https://proxy-seller.com/zh/?action=login

   这是我自己在用、也实测验证过的一家。

   ProxySeller 的付款方式只收：
       Visa / Mastercard 信用卡、PayPal、USDT

   ★ 这几种付款方式你一个都没有怎么办？

     · 可以在你购买本工具的平台上私信我，我们再商量怎么处理。

       详细的购买步骤见随包的《ProxySeller网站ISP购买问题.txt》。

     · 也可以自己换一家买。这个工具不挑服务商，只要你买到的是
       「美国的静态住宅 / ISP 代理」，最后能拿到【IP、端口、账号、密码】
       这四样，就能用。

       ★ 但一定要先问清楚：这家允不允许中国大陆的 IP 直连。
         有的服务商封禁大陆 IP，你买之前没法自己验证，买完了这个
         工具也测不出来，很容易白花钱。

     买之前认准三点：
         ① 地区选美国
         ② 类型是 ISP / 静态住宅
            （不要买机房/数据中心的，也不要买按流量计费的动态住宅）
         ③ 支持 SOCKS5 或 HTTP

     有的服务商用「IP 白名单」授权、不给账号密码，这种也能用，
     到时候账号密码留空就行。

3. 大约 20 块钱
   · 机场（梯子）：1 块钱 10G 起
   · 美国住宅 ISP：约 3 美元 / 月

   ★ 关于「一次性订阅链接」
     有些机场发的订阅链接只能用一次，网站上会写「此链接仅可使用一次，
     客户端打开后即失效，如需再次导入请重新生成」。

     这种链接不要提前用浏览器点开去看，也不要先导进别的客户端——
     点开一次就废了，本工具再导入就会失败。
     复制下来直接粘给本工具即可。

     万一已经用掉了：回机场网站重新生成一条。工具在导入失败时
     会直接问你要新链接，当场粘进去就行，不用从头重跑。


【工具会帮你搞定的】

· 自动安装 Clash（安装包已经打包在里面了，不用你翻墙下载）
· 自动配置链式代理、分流规则
· 自动检查你的 IP 干不干净、有没有泄露
· 没有 ISP 的话，会帮你打开 ProxySeller 的购买页面
  （机场需要你自己准备，本工具不提供也不销售任何网络服务）


【你的电脑需要有】

· Windows 系统
· Chrome 或 Edge 浏览器（Windows 一般自带 Edge，通常不用管）


【随包还有两份文档，按需要看】

· 《ProxySeller网站ISP购买问题.txt》
  卡在买 ISP 那一步就看它。哪个产品别选错、哪两个选项千万别勾、
  买完在后台哪里看 IP 和账号密码，都写了。

· 《在终端里用ClaudeCode.txt》
  只在浏览器里用 Claude 的不用看。
  要在终端里敲 claude 命令的必须看 —— 那种用法光开「系统代理」
  是不够的，而且不会报错，你会以为配好了其实没有。


========================================
  关于隐私（请放心）
========================================

· 你填的账号密码只保存在你自己的电脑上（C:\用户\你的名字\.claude-net\）
· 不会上传到任何地方，作者也看不到
· 这个程序里没有任何其他人的账号信息


========================================
  ⚠️ 配置完成后，有一件事千万别做
========================================

  别去点 Clash 里【代理】页面右上角的「链式代理」按钮！

那个按钮有 bug（Clash 官方已知问题），点一下，配好的东西就全丢了，
而且取消勾选也回不来，要重启软件。

到时候你会发现 Claude 突然打不开，还完全想不到是这个原因。

正常使用根本不需要点它。


========================================
  出问题了怎么办
========================================

配置完成后，工具会在这个位置生成一份《使用须知》：

    C:\用户\你的名字\.claude-net\使用须知.md

里面有：
  · 日常怎么用
  · 养号建议（很重要，尤其是新注册的号）
  · 指纹浏览器怎么配
  · 常见故障速查表

想检查网络还正不正常：再双击一次 claude-net.exe 就会自动体检。


【出错了要发什么给我】

每次运行都会自动记日志，出问题就把这个文件发我：

    C:\用户\你的名字\.claude-net\运行日志.txt

里面记录了程序做了什么、卡在哪一步。
密码和订阅 token 已经自动打码成 ***，可以放心发。

★ 注意：同目录下的 state.json 里有你的账号密码明文，那个不要发给任何人。


【想从头再来怎么办】

在 claude-net.exe 所在的文件夹里，按住 Shift + 鼠标右键 →
选「在此处打开 PowerShell / 终端」→ 输入下面这行回车：

    .\claude-net.exe reset

然后重新双击 exe 就是全新开始了。
