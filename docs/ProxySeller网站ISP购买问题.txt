========================================
  ProxySeller 网站 ISP 购买问题
  Claude 稳定网络环境配置工具
========================================

很多人卡在 ProxySeller 买 ISP 这一步，
这份文档把整个流程一步步写清楚。


========================================
  一、先确认你有付款方式
========================================

ProxySeller 只收这三种：

    · Visa / Mastercard 信用卡
    · PayPal
    · USDT

★ 三种你一个都没有怎么办？

  可以在你购买本工具的平台上私信我，我们再商量怎么处理。

  也可以自己换一家支持你付款方式的服务商 —— 本工具不挑服务商，
  只要买到的是「美国的静态住宅 / ISP 代理」，最后能拿到
  【IP、端口、账号、密码】这四样就能用。


========================================
  二、购买步骤（照着做，别自由发挥）
========================================

购买地址：https://proxy-seller.com/zh/?action=login


第 1 步　注册账号

  先把账号注册好，后面所有操作都在这个账号里。


第 2 步　在主页选对产品

  选「ISP」。

  ★ 这一步最容易买错，务必看清：
      不要选「住宅代理」——那是按流量计费的动态住宅，IP 会变
      不要选「IPv4」——那是机房 IP，不是住宅 IP

  选好 ISP 之后：
      地区选　美国
      时长选　一个月
  然后点购买。


第 3 步　购买面板里的两个坑

  点购买后会弹出一个购买面板（Dashboard）。

  (1) 选时长
      一个月通常是 3 美金左右。

  (2) 「百分之百正常运行时间」这个选项 —— 不要勾

      ★ 为什么：勾了它，服务商会在 IP 出问题时自动给你换一个。
        听起来很好，但我们这套方案需要的是固定不变的 IP。
        IP 一换，之前配好的链式代理就全对不上了。

  (3) 最底下「身份验证方式」—— 选「用户名和密码」

      ★ 不要选旁边的「静态 IP」（IP 白名单授权）。
        选了它，代理只认你当前这个公网 IP，
        而我们是让机场的境外节点去连它的，来源 IP 对不上，
        会直接被拒绝。


第 4 步　付款

  按网站流程付完即可。开通可能需要等一会儿。


========================================
  三、买完之后，去哪里看 IP 和账号密码
========================================

  1. 进入你的个人 Dashboard（后台）
  2. 把鼠标移到刚买的那条 ISP 上
  3. 会显示出来：
         IP 地址
         两个端口
         账号
         密码

  ★ 把这四样完整保存下来，运行脚本时要用。

  ★★★ 两个端口都要填，这是最容易踩的坑 ★★★

    它给你两个端口，比如 50100 和 50101：
        小的那个（50100）是 HTTP 口
        大的那个（50101）是 SOCKS5 口

    后台里 HTTP 那个排在前面，很多人顺手只复制了第一个。

    两个都填，中间空一格，像这样

        50100 50101

    你不用管哪个是哪个 —— 脚本会自己逐个实测判断，并且优先用
    SOCKS5（目前看 SOCKS5 更稳）。只填一个的话，万一那个不合用，
    前面每一步都会显示成功，要到最后一步「出口自检」才暴露出来。

  ★ 万一填了两个、到「出口自检」还是不通

    端口不是唯一的原因，别只盯着它查。也可能是机场的前置节点连不到
    ISP（换个节点再试），或者 ISP 那边本身有问题（IP 过期、被停）。
    按工具当时给你的提示走 —— 它会按最可能的原因排好顺序。

  ★ 最省事的填法：网站上有一键复制的话直接复制整行，
    形如  IP:端口:账号:密码
    粘贴给脚本即可，它能自动拆解。


========================================
  四、万一买到的是机房 IP —— 可以要求换
========================================

  脚本在「出口自检」那一步如果告诉你

      被识别为 机房 / 数据中心 IP

  别急，钱不用白花，ProxySeller 是可以换的。按这三步走：


  第 1 步　拿到证据

    用浏览器打开下面这个地址（把 <你的IP> 换成脚本告诉你的那个）：

        https://ip.net.coffee/ip/<你的IP>

    截一张图。

    ★★★ 截图里一定要拍到 data center 或 DCH 这样的字样 ★★★

      那是你的证据。光跟客服说「这是机房 IP」是没用的，
      对方会让你自己举证。


  第 2 步　发给客服

    去 ProxySeller 网站上找在线客服，把截图发过去。


  第 3 步　把话说清楚

    配一句话，中文英文都行，意思是：

        「我刚买了一个 IP，地址是 <你的IP>，
          在这个网站上检测出来是数据中心（data center），
          不是我需要的住宅 IP，希望换一个。」

    英文版可以直接抄这句：

        I just purchased an IP: <你的IP>
        This site shows it as a data center IP, not a residential ISP IP.
        Could you please replace it with a residential one?


  按我们的经验，客服会给换。

  换好之后，你会拿到新的 IP 和端口 —— 重新双击本程序，
  按提示把新的填进去就行，不用从头重配。
